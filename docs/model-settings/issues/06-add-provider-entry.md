# 6: 添加提供商入口

**labels:** [ready-for-agent]
**Blocked by:** 2（设置页主从布局与供应商列表）

**What to build:** 右上「添加提供商」→ 右栏整体切换为添加页（顶部返回按钮回详情）：两张入口卡对齐 ZCode「创建即编辑」，不用模态向导。① 从模型目录导入：现有目录浏览器移入右栏（提供商行 logo 上墙；端点为空的目录提供商显示「需填写端点」warning 徽标，导入后详情端点区呈必填态引导），导入成功自动选中新供应商进入详情；重复导入同一目录提供商的既有去重提示保留。② 手动创建：右栏内嵌表单（名称 / 协议 Select / 端点 / 密钥可选 / 首个模型 ID + 上下文窗口），保存走既有 providerSave 校验，成功后新供应商出现在「手动添加」组并选中进入详情。详见 spec §7 添加提供商、§3.2。

## 验收标准

- [ ] 添加页返回按钮可用，返回后详情恢复正常
- [ ] 目录导入全流程在右栏完成（搜索 → 选提供商 → 勾模型 → 导入），导入后自动选中
- [ ] 无端点提供商在目录行显示徽标，导入后详情端点区呈必填态
- [ ] 手动创建：必填校验内联报错；成功后新供应商入列并选中
- [ ] 重复导入同一目录提供商提示「已添加」
