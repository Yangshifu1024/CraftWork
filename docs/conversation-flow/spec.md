# spec：对话流运行期行为（防垂直晃动）

任务执行期间（模型流式输出 + 工具调用）消息流的垂直稳定性约定。背景：流式内容增长、工具状态切换、折叠块开合，叠加 use-stick-to-bottom 默认弹簧的滞后追赶与回弹，形成持续的上下晃动。对标 ZCode 的核心设计：**流式进行中内容只追加、几何只增不减；形态转换只在 run 结束边界发生，且必须带显式过渡**。

## 行为约定

1. **贴底不做弹簧追赶**：内容增高触发的贴底跟随不走平滑动画——`use-stick-to-bottom` 的 `resize` 默认 `"instant"`（新内容直接就位）；「平滑跟随」设置（`settings.smoothFollow`）开启后才走库默认弹簧，作为可选观感。程序化贴底一律 instant 直写，不用 smooth / 弹簧中间帧（平滑中间帧会被库的滚动判定与视觉跟踪放大成晃动）。
2. **工具行流式中不合并**：`status === "streaming"` 的消息内所有工具（running / done / error）一律渲染为独立单行摘要；完成时原位换状态文字与耗时，行高不变，行数只增不减。「连续同名工具归并为组卡」只在历史折叠块中生效（run 结束后的压缩呈现，用户不逐帧观察），禁止在流式期间发生「独立卡 ↔ 组卡」的形态互转。
3. **折叠块收起带过渡**：`WorkFold` 在 run 结束自动收起时做 300ms `grid-template-rows` 高度过渡，过渡结束后再卸载内容（防整块过程内容无过渡蒸发，也防过渡期间超高空白）；`prefers-reduced-motion` 下直接跳变（`motion-reduce:transition-none`）。
4. **正文无流式动画**：正文 Markdown 不做流式淡入 / 打字机动画（`stream-fade-in` 仅限旁路图片预览等一次性入场场景）；流式状态切换不得导致正文子树重挂、重闪。
5. **正文锚定不搬家**：流式期间正文起点锚定**第一个非空 text part**（parts 只追加，该选择逐帧稳定），后续正文段与其后的过程行按序平铺追加；run 结束按既有语义「最后一个非空 text」重算切段，此时发生的重组与折叠收起属于同一次显式形态转换。
6. **轮尾运行中槽位**：run 期间在消息尾部显示固定槽位（`min-h` 常驻）的「工作中 · N 秒」指示；计时器为独立小组件（100ms 自刷，只重渲染计时本身，不重渲染对话），数字 `tabular-nums` 防宽度抖动；等待审批时让位——审批卡是唯一进度反馈（对齐 ZCode 轮尾 ChatLoading 的互斥裁决：只对「等待用户操作」互斥）。
7. **审批卡常驻仅限等待中**：只有 `waiting` 状态的审批卡常驻渲染在折叠区之外（run 推进的关键路径）；已决定卡立即回归时序位置（流式中折叠区默认展开，卡片仍可见），run 结束后随切段归档折叠区。曾试验「已决定卡原位留存至 run 结束」（决定瞬间不回落的防高度突变），但计划审批批准后的实施阶段长达数分钟，卡片始终垫底挤压视口——确定性回归时序位置优先。

## 实现落点

- 滚动与贴底：`src/renderer/src/components/conversation.tsx` 的 `Timeline`。
- 工具行合并开关、折叠过渡、正文切段锚定、轮尾槽位、审批常驻：同文件 `TurnBody` / `WorkFold` / `WorkLines` / `coalesceToolRows` / `RunLoadingSlot`。
- 正文动画：`src/renderer/src/components/markdown.tsx`（正文不挂任何动画类）。
