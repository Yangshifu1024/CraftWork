# 5: 空会话一次性清理迁移

**labels:** [ready-for-agent]
**Blocked by:** None（可与票 1 并行）

**What to build:** 追加数据库迁移版本，一次性删除遗留空会话：无任何事件、自动命名、标题为「新对话」的线程。升级后侧栏与搜索不再出现历史空会话；有事件或被手动改名的会话一律保留，迁移版本递增且旧库可正常重开。

## 验收标准

- [ ] store 层迁移测试：空自动命名会话被删除；含事件的会话保留；手动改名（非自动命名）会话保留
- [ ] 迁移版本递增，旧库重开与后续读写正常
- [ ] 升级后搜索「新对话」不再命中任何空会话
