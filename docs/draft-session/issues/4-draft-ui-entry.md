# 4: 草稿态入口与配套界面

**labels:** [ready-for-agent]
**Blocked by:** 2（渲染层草稿态最小闭环）、3（草稿槽按归属分桶与持久化）

**What to build:** 草稿态的入口与配套界面补全：接通票 2 暂禁用的草稿态模型选择——选择只更新当前草稿槽（不发送任何写模型请求），首发后新会话继承该模型；项目分组新增「在该项目下新建会话」入口（hover 显示），点击进入该项目草稿槽并恢复其内容；新建项目流程收尾同样落在项目草稿态；草稿态顶部标题显示归属——临时显示「新对话」，项目槽显示项目名。

## 验收标准

- [ ] 草稿态选择模型不产生任何写请求；首发后新会话使用该模型
- [ ] 项目分组「+」入口进入该项目草稿槽，切换其他草稿再回来内容不丢
- [ ] 新建项目流程结束后停留在该项目草稿态
- [ ] 草稿态顶部标题正确显示归属（「新对话」/ 项目名），深浅主题下显示正常
- [ ] 项目草稿态下右侧面板显示该项目内容（文件树 / 终端等），发送前即可浏览项目；临时草稿态维持内置临时目录
- [ ] 隔离目录冒烟走查上述场景
