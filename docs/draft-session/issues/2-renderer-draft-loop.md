# 2: 渲染层草稿态最小闭环——新建不再落库

**labels:** [ready-for-agent]
**Blocked by:** 1（「创建并首发」主进程原子路径）

**What to build:** 新建对话变为纯界面草稿态：侧栏「新建对话」/ ⌘N / ⌘K 不再调用线程创建，仅把当前活动会话置空进入草稿态（界面不持有 Node 能力，草稿是渲染层状态，主进程不感知）。草稿态输入后按 Enter 走「创建并首发」：成功后会话立即出现在侧栏并选中、草稿清空、时间线显示用户消息与回复；失败（含未配置模型）草稿文本与附件完整还原并 toast 报错。重复触发新建永远回到同一个草稿，未发送内容保留。

## 验收标准

- [ ] 点新建 / ⌘N / ⌘K 后侧栏与数据库均无新会话（彻底消除空「新对话」来源）
- [ ] 草稿态发送成功：会话以首条消息短标题出现在侧栏对应分组，时间线完整
- [ ] 未配置模型时发送：报错 toast、草稿还原，侧栏与数据库零痕迹
- [ ] 草稿态下附件、模式切换等输入区能力照常可用
- [ ] 隔离目录冒烟完整走查上述场景（Code / Work 两模式）
