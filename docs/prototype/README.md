# CraftWork 高保真可交互原型

本目录是《Go 原生桌面 Agent 产品需求文档》v3.0 的配套高保真原型，用于产品评审、交互确认与视觉走查。

> **边界说明**：原型使用 HTML / CSS / JavaScript 编写，仅用于演示交互与视觉，**不是正式实现**。正式产品按需求文档的硬约束使用 Go 原生界面与图形层，**不使用任何 WebView**（排除 Electron、Tauri、Wails、WebView2、CEF、Qt WebEngine）。

---

## 一、打开方式

**方式 A：直接打开**

双击 `index.html`，用 Chrome、Edge 或 Safari 打开即可。脚本按普通 `<script>` 顺序加载，不依赖构建工具与网络。

**方式 B：本地静态服务器（推荐）**

```bash
cd docs/prototype
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

推荐方式 B 的原因：`file://` 下部分浏览器会限制 `localStorage`，主题、模式与面板宽度的持久化可能失效；本地服务器下这些偏好会正常保留。

## 三、建议的体验路径

### 界面入口约定（评审反馈）

- **没有独立顶栏**：左侧栏标题行（CraftWork）、聊天头部、右侧面板标签栏共用页面顶部 48px 的一行；Code / Work 切换位于左侧标题行下方。
- 工作区切换：左侧工作区卡片右下角的向下箭头。
- 审批档位：输入框底部左侧的盾牌按钮（分级 / 严格 / 只读），与设置 · 工具与权限中的「审批档位」双向同步。
- 模型切换：输入框右下角，位于上下文估算与发送按钮之间。
- 工具范围：底部状态栏右侧（Code 显示「17 个内置工具 · Shell 已启用」，Work 显示「文档 · 文件 · MCP」）。
- 命令面板与设置：左侧栏底部第二行（「用量 / 审计」的下一行），快捷键 `⌘K` / `⌘,` 仍然有效。
- 等待审批、运行中、出错等状态：聊天头部徽章、线程列表状态点与状态栏计数。

### 窗口布局

- 页面顶部没有独立顶栏：左栏标题行、聊天头部与右栏标签栏同处一行（48px），三栏内容从同一水平线开始。
- 左侧栏固定 268px，**不可拖动、不可折叠**。
- 右侧栏在窗口宽度小于 1180px 时自动折叠，聊天区占满剩余宽度；聊天头部的面板按钮可把右栏以浮层形式打开（覆盖聊天区，不挤压中间内容）。
- 面板标签栏右上角的「全屏」按钮会把右栏放大到覆盖中间区域（左侧栏、顶栏与状态栏保持可见）；再次点击或按 `Esc` 恢复分栏。
- 宽窗口下右侧栏仍可拖动左边缘调整宽度；窄窗口与全屏状态下拖拽把手隐藏。


### 路径 1：Code 模式完整闭环（约 1 分钟）

1. 打开后默认进入 Code 模式，线程「修复登录刷新超时」处于**等待审批**状态。
2. 在内联审批卡片上点击「允许一次」。Agent 会继续执行：
   - 工具卡片 `fs_edit`、`fs_write` 完成，任务清单推进；
   - 弹出第二道审批 `shell_exec`（R2 执行）；
   - 再次允许后，测试输出出现，任务清单全部完成，线程回到空闲。
3. 点击审批卡片上的「查看完整差异」，右侧切换到差异面板：
   - 可以在「统一 / 并排」之间切换；
   - 逐块「应用此块」或「跳过」，底部统计会更新；
   - 应用后，编辑器里的 `session.go` 会显示修复后的内容。
4. 在文件树里点击 `internal/auth/session.go`，可以查看语法高亮、行号、搜索与只读/编辑切换。

### 路径 2：Work 模式文档闭环

1. 顶部切换到 **Work**，界面会隐藏 Git、代码差异、终端与 Shell；右栏变为「文档 / 差异 / 文件」。
2. 线程「整理季度会议纪要」有等待中的 `doc_write` 审批：
   - 审批卡片展示**文本级差异**；
   - 允许后，右侧 Word 预览中姓名笔误被修正（黄色高亮），原待办表之后新增「待办事项汇总」表（绿色高亮）；
   - 顶部出现「写入已通过审批 · 原文件已备份」，可查看文本级差异或恢复上次写入。
3. 线程「修正预算表合计公式」演示 Excel：
   - 审批通过后 `B8 / C8 / D8` 高亮为 `520,000 / 505,200 / −14,800`；
   - 点击任意单元格，公式栏显示对应公式；底部可切换工作表。
4. 线程「阅读产品方案 PDF」演示只读 PDF 与「不支持 OCR」提示。
5. 线程「汇总本周邮件并草拟回复」演示邮件只读、应用内草稿与「不会自动发送」提示。

### 路径 3：其他可试交互

- **审批档位**：输入框底部的盾牌按钮，在「分级 / 严格 / 只读」之间切换。严格与只读会隐藏审批卡片里的「本会话允许 / 本工作区始终允许」，只保留「拒绝 / 允许一次」；卡片头部会标注当前档位。设置 · 工具与权限里的同名选项与它双向同步。
- **命令面板与设置**：入口在左侧栏底部第二行（「用量 / 审计」的下一行），也可用 `⌘K` / `⌘,`。顶栏不再放全局操作按钮。
- **模型切换**：入口固定在输入框右下角（上下文估算右侧、发送按钮左侧，带间隔），点击展开列表。顶栏、线程头部与状态栏不再提供模型切换或模型展示。
- **工具范围**：原输入框里的「文档 · 文件 · MCP / 17 个内置工具」已移到底部状态栏右侧，悬停可看完整说明（Work 模式不提供 Shell、Git 与终端）。
- **工作区切换**：入口固定在左侧工作区卡片右下角的向下箭头；顶栏不再提供工作区控件。
- **设置中心**：`⌘,` / `Ctrl+,` 或左侧栏底部的「设置」按钮。七组设置均可交互：切换主题、测试提供商连接、迁移环境变量密钥、启停 MCP 服务器、撤销工作区信任等。
- **终端**：Code 模式右侧「终端」标签。输入 `git status`、`go test ./...`、`help`、`clear` 等命令；`↑ ↓` 浏览历史。
- **审计与用量**：侧栏底部「审计」「用量」，或点击状态栏的「待审批 / 上下文」。
- **主题**：设置 → 外观，在深色与浅色之间切换；代码主题、字号等选项会保存到本地。
- **拖放与附件**：把文件拖到聊天区，或点击输入框的附件按钮；单条最多 20 个、单文件 50 MB 的提示已内置。
- **中断**：流式生成时点击停止按钮或按 `Esc`，等待中的审批会一并取消。

| 数据与审计（F-DATA） | 审计表、用量聚合、备份列表与恢复、导出不含密钥、遥测固定关闭 |

## 六、演示数据说明

- `craftwork` 是一个虚构的 Go 仓库，文件内容、Git 状态、测试输出均为演示数据。
- Word / Excel / PDF 内容均为模拟，不是真实文档；预览用 HTML 模拟纸张与网格，不执行宏、不解析真实二进制。
- 所有工具调用、审批、审计、用量都在前端内存中模拟，不会发起网络请求，也不会读写磁盘。
- 「复制」按钮会写入系统剪贴板；「用系统浏览器打开链接」只弹出确认框，不实际打开页面。
- 刷新页面会重置对话与审批状态；主题、模式与面板宽度会保留在 `localStorage`。

## 七、已知限制

- 界面语言固定为简体中文；设置中的 English 选项仅作展示，不切换文案（需求中的完整国际化需要接入消息编号表）。
- 代码编辑器为只读预览；切换到编辑态后可以输入，但保存只会提示「原型演示」，不写盘。
- Markdown 渲染是轻量实现，覆盖标题、列表、任务列表、引用、分隔线、表格、代码块、行内格式与链接；复杂嵌套语法可能不完全还原。
- 终端为命令模拟，不支持真实伪终端、光标定位与全屏程序（如 vim、top）。
- 审批与审计不落库；「恢复备份」「导出数据」等操作只给出反馈，不产生真实文件。
- 屏幕阅读器支持有限，与需求文档中的可访问性说明一致。

## 八、修改与缓存

`index.html` 中的样式与脚本引用带有 `?v=16` 版本参数，用于避免浏览器复用旧缓存。修改 `js/` 或 `*.css` 后，把该版本号递增（例如改为 `?v=17`）再刷新页面即可。

如需调整演示内容，优先修改 `js/data.js`（线程、消息、文件、文档、终端、MCP、审计）与 `js/scenarios.js`（流式回复与审批后续流程），界面渲染逻辑集中在其余模块。
