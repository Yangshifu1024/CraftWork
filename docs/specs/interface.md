# CraftWork 界面规格

本文件是界面的视觉与交互基准。布局尺寸、token 与交互行为以本文件为准；组件与后端的对应关系见 `architecture.md` 第 5 节。

## 1. 设计目标与原则

1. **让 Agent 的工作过程可见**：读文件、调工具、等待审批、写入差异、运行测试，每一步都有明确位置与状态。
2. **把风险放在用户眼前**：审批展示原始路径、命令、风险等级与影响范围；审批卡片默认拒绝，主要视觉权重不在「允许」。
3. **两种模式、一套骨架**：Code 与 Work 共享三栏结构与工作区，只改变可用工具、右侧面板内容与会话列表。
4. **专业工具的密度感**：13–14px 基准字号、紧凑的 24–32px 控件、清晰的分隔线，避免大圆角与过度留白。
5. **键盘优先**：常用操作两次按键内可达，焦点始终可见，状态不只依赖颜色。

| 原则 | 落地方式 |
| --- | --- |
| 本地优先 | 所有状态与数据在本地；界面不出现云端同步、账号登录等入口 |
| 审批不诱导 | 默认焦点在「拒绝」；R3 / R4 不提供永久允许 |
| 信息分层 | 主操作（发送、允许一次）与次要操作（更多、复制）通过位置与字重区分 |
| 渐进披露 | 工具输出、推理内容、文件树、差异详情默认折叠，按需展开 |
| 一致性 | 同一语义同一组件与颜色：风险等级、状态点、徽章、卡片结构 |
| 可撤销感 | 写入前备份、软删除 7 天、差异逐块应用，界面持续提示可恢复 |

## 2. 整体框架

页面没有独立顶栏。左侧栏标题行、聊天头部、右侧面板标签栏共用页面顶部 48px 的一行（ADR-0012）。

```text
【顶部 48px，一行】
  左侧：CraftWork 标题
  中间：会话标题 · 模式徽章 · 状态徽章 · 会话操作（面板 / 重命名 / 复制 / 归档 / 更多）
  右侧：面板标签（文件 / 差异 / 终端）· 全屏 · 刷新

【主体三栏】
  左侧 268px：模式切换 → 工作区卡片 → 会话列表
  中间：消息流 → 输入区（最大内容宽 880px，居中）
  右侧：文件树 / 编辑器 / 差异 / 终端；Work 模式为文档预览 / 文本级差异 / 文件
```

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| 顶部行 | 48px | 左侧标题行、聊天头部、面板标签栏统一高度 |
| 左侧栏 | 268px 固定 | 不提供拖拽与折叠 |
| 聊天区 | 自适应 | 最大内容宽度 880px |
| 右侧面板 | 默认 320px（最小宽度），可拖拽至 760px | 窄窗口自动折叠 |
| 最小窗口 | 960 × 640 | 低于 1180px 宽时右栏折叠 |

窗口行为：

- 左侧栏固定 268px，不可拖动、不可折叠。
- 窗口 < 1180px 时右栏自动折叠；点击聊天头部面板按钮以浮层覆盖聊天区右侧（不挤压聊天内容）。
- 面板全屏：从左侧栏右边缘覆盖到窗口右侧；再次点击或 `Esc` 恢复。
- 跨阈值缩放：缩窄时自动折叠并退出全屏；放大时恢复三栏。
- 主题、模式、面板宽度本地持久化；窗口尺寸由系统恢复。
- 折叠动画约 260ms 缓动；拖拽调整宽度期间禁用过渡；浮层与全屏态不参与裁切以保留外投影。

## 3. 左侧栏

```text
268px 左侧栏（自上而下）
├─ 48px 标题行：CraftWork（居中）
├─ 模式切换：Code | Work（占满宽度）
├─ 工作区卡片：名称 / 路径 / 信任 / 分支 / 切换箭头
├─ 会话区标题：CODE 会话 + 数量 + 搜索 + 新建
├─ 会话列表（可滚动）
└─ 底部两行：用量 / 审计；命令面板 / 设置
```

- **模式切换**：整体高 40px、圆角 10px 深底描边轨道；两个等宽按钮（图标 + 文字，高 32px）；选中项为模式强调色实底滑块（Code 蓝底白字、Work 琥珀底白字，深色主题 Work 为琥珀底深字），160ms 缓动平移，滑块带模式色软投影。切换后会话列表、面板内容、输入框占位立即变化，工作区不变。
- **无工作区卡片**：侧栏模式切换下不再展示工作区卡片（名称、路径、信任徽章、Git / 文档徽标与切换箭头均已移除）；当前工作区身份通过会话列表的分组标题体现。工作区切换、添加与信任调整暂无界面入口，待命令面板补齐。
- **会话列表**：无独立列表头行，按归属分组展示：
  - 置顶「临时会话」组：闪电图标（紫色）、名称、数量徽章与右侧「+」按钮（新建临时会话）；不折叠。
  - 「项目会话」区：组头为文字标题 + 会话总数徽章，右侧「+」（创建项目：系统目录选择后添加项目工作区、激活并立即新建该项目会话）。
  - 每个项目一个分组：组头行左侧文件夹图标可点击展开 / 折叠（展开 `folder-open`、折叠 `folder`，状态持久化到本地，默认展开），随后是项目名与数量徽章；组内默认最多显示最近 5 条，超过时底部「显示更多」按钮，每次点击再展示 5 条。
  - 工作区已被移除的会话归入末尾「其他」组。
  - 列表项两行（标题；时间在左、状态在右——运行中脉冲点、等待审批黄、错误红、已完成灰；内容命中显示橙色标记）。当前会话背景 `--bg-active` + 左侧 2px 模式强调色竖条。右键菜单：复制会话 Id、重命名、删除（危险样式，确认后连同消息、事件与审批一起删除）。
- **自动命名**：首轮消息后标题仍为「新对话」时，首条消息 ≤ 20 字符直接使用，否则调用当前模型生成；失败回退首条消息提取；手动改名后不覆盖。
- **搜索**：按标题与消息内容过滤，只在当前模式的会话内进行。
- **底部两行**贴底（`margin-top: auto`）：用量、审计；命令面板 `⌘K`、设置 `⌘,`。

## 4. 聊天区

### 4.1 会话头部

高度 48px；标题一行省略；模式徽章用模式色，状态徽章按运行中 / 等待审批 / 出错；右侧按钮：面板开关、重命名、复制会话、归档、更多（含软删除）。背景为 `--bg` 与 `--bg-panel` 混合色带轻微模糊。

### 4.2 消息布局

聊天软件式布局，不使用头像与作者名。

| 角色 | 布局 |
| --- | --- |
| 用户 | 靠右侧气泡：`--mode-accent-soft` 底、1px `--mode-accent-line` 边框、圆角 12px（右下 4px）、最大宽度 78%；时间贴气泡下右侧 |
| 助手 | 全宽无边框内容区；时间在消息末尾 |
| 系统提示 | 居中细条，灰色或琥珀色（「上下文已压缩」「已停止生成」等） |

元信息行含时间与「已被替代」「生成中」标签（常显）；复制 / 重新生成按钮悬停浮现（用户消息：复制；助手消息：复制、重新生成）。

### 4.3 内容块

| 内容块 | 视觉与交互 |
| --- | --- |
| Markdown 文本 | 13px / 1.68 行高；标题 15–17px；列表、引用、分隔线、表格、任务列表齐全 |
| 行内代码 | 等宽、`--bg-active` 底、4px 圆角 |
| 文件引用 `path:line` | 蓝色描边 chip，裸文本与反引号行内代码形式都生效（围栏代码块内不转换）；点击在右侧文件面板打开并垂直居中目标行 |
| 代码块 | 语言标签、行号开关、自动换行、复制、超长折叠；复制不含行号 |
| 推理内容 | 虚线边框折叠条，显示耗时；默认折叠，展开 11.5px 次要文本 |
| 工具卡片 | 左侧状态色竖条（运行中蓝 / 完成绿 / 失败红 / 等待黄）；工具名、风险徽章、参数摘要、耗时；展开参数与输出，可复制 |
| 待办卡片 | 任务清单 + 进度条 + `2 / 4` 计数；完成项勾选删除线，进行中高亮 |
| 审批卡片 | 见 4.4 |
| 错误卡片 | 红色边框；错误分类、原因、按错误码的处理建议、重试 / 切换模型 / 复制 |
| 邮件草稿卡 | 收件人、主题、正文、生成时间；「仅应用内显示」徽章与复制按钮 |
| 提示条 | 信息 / 警告 / 成功 / 强调四种 |

### 4.4 审批卡片

```text
┌── 2px 风险色条 ───────────────────────────────────────
   需要你的批准    R1    fs_edit                  等待决定
   摘要：把 Exchange 网络调用移出写锁，回写前做二次检查
   路径：internal/auth/session.go
   事实：修改 2 个文件 · 写入前备份 · R1 写工作区
   差异预览（可展开）                          查看完整差异
     -  s.mu.Lock()
     +  sess, ok := s.sessions[sid]
   操作：拒绝 | 允许一次 | 本会话允许 | 本工作区始终允许
   提示：默认选中「拒绝」；Esc 拒绝；R3 / R4 不提供永久允许
```

- 风险徽章使用 R0–R4 专用颜色，只出现在风险语境，不做装饰。
- 展示工具名、原始路径或命令、影响范围；文档写入额外展示段落 / 单元格级差异。
- 默认焦点在「拒绝」，不允许默认选中「允许」。
- 允许范围：拒绝、允许一次、本会话允许、本工作区始终允许；R3 / R4、严格与只读档位、受限工作区仅前两项（自由档位不再出现审批卡片）。
- 决定后卡片变绿（已允许）或灰（已拒绝），显示时间、范围与「已写入审计」。
- 多个审批排队逐个处理；`Esc` 在无浮层、无全屏面板时拒绝最近一条审批。

### 4.5 输入区

| 位置 | 元素 | 说明 |
| --- | --- | --- |
| 左侧 | 附件、图片 | 支持拖放与粘贴；模型不支持图片输入时禁用图片按钮 |
| 左侧 | 审批档位 | 盾牌图标 + 分级 / 严格 / 只读 / 自由；与设置双向同步；自由档位下整体转危险色 |
| 右侧 | 上下文占用 | 圆环 + 输出速度 + 百分比（<50% 灰、50–80% 黄、≥80% 红）；点击展开详情 |
| 右侧 | 模型选择 | 状态点 + 模型名 + 箭头；按模型 / 提供商搜索；列表为空时禁用发送 |
| 右侧 | 发送 / 停止 / 引导 | 发送为模式强调色方块；运行中按输入内容切换：有内容显示「引导」按钮（与发送同形、箭头改为回折角，背景中性色、悬停变强调色），空输入显示停止按钮 |

- 输入框默认两行，随内容自动增高（最大 220px）；空输入且无附件时禁用发送。
- 运行中回车 / Ctrl（⌘）+Enter / 点击「引导」按钮即发送运行中引导（steer）：消息气泡立即出现在运行中回复之后，带「待送达」虚线徽标，在当前工具批次结束后并入下一次模型请求；徽标在后续流式输出、工具开始或运行终态时消失。
- 等待审批时提示先处理审批或停止 run。
- 附件以 chip 展示可移除。
- 下方提示条固定显示快捷键。

### 4.6 滚动与空状态

- 默认跟随底部；上滚超过 80px 停止跟随并显示「回到底部」；新消息到达时正在跟随才自动滚动。
- 空会话显示模式图标、标题、说明与三条建议快捷输入。

## 5. 右侧面板

标签：Code 为文件、差异、终端；Work 为文档、差异、文件。标签栏高 48px；差异标签带未应用文件数徽章，终端标签带标签数徽章；右侧固定全屏与刷新按钮；左边缘 6px 拖拽热区（浮层与全屏时隐藏）。

- **文件树**：过滤输入框、全部折叠；元信息（仓库名、文件数、变更数、Git 状态）；缩进 13px/层；文件按扩展名着色；Git 状态字母 `M / A / D / U` 在最右（Work 不显示）。点击在编辑器打开；右键菜单：打开、复制相对路径、在文件管理器中显示、移到废纸篓。工作区挂载多个源文件夹时按文件夹分段，段头为目录名 +「主要」徽标；Git 状态只标注主要目录段。
- **创建项目对话框**（`CreateProjectDialog`）：标题「创建项目」+ 关闭；项目名称输入（占位「新项目」）；设备下拉样式（静态「此电脑」+ 显示器图标）；源文件夹区——空态为虚线大按钮「选择文件夹」+ 说明「CraftWork 可读取和编辑这些文件夹」，已选态为列表行（目录名 + 首项「主要」徽标 + 移除 ×）+「添加文件夹」行；底部「取消 / 创建项目」（无源文件夹时禁用）。信任确认视图：标题「信任此文件夹吗？」（多文件夹为「信任这些文件夹吗？」）+「此电脑」+ 等宽绝对路径列表 + 说明文字 +「取消 / 信任文件夹并创建」，初始焦点在取消按钮。
- **代码编辑器**：面包屑、语言徽章、只读 / 编辑中徽章；行号列固定、当前行左侧 2px 强调色；底部状态（行数、编码、换行符）；保存前确认并提示自动备份；外部修改阻止覆盖。
- **代码差异**：摘要（文件数、`+42 −7`）、文件列表（待应用 / 已应用徽章）、统一与并排视图（空行斜纹占位）；每个差异块可「应用此块」「跳过」；底部「应用当前文件全部块」；应用后降透明度并提示备份状态。
- **终端**：多标签（可新建关闭，关闭提示进程组清理）；头部显示当前目录、Shell 类型、「用户终端不经过 Agent 审批」；xterm.js 连接真实 PTY。
- **文档预览（Work）**：Word 纸张页面（变更段落黄高亮、新增绿高亮）；Excel 公式栏 + 网格 + 工作表标签（变更单元格黄底描边）；PDF 只读页面（扫描页提示不支持 OCR）。工具栏：文件名、格式与大小、缩放 70–150%、备份、只读 / 已写入徽章；外部修改提示条（重新加载 / 保留当前）；写入完成显示「写入已通过审批 · 原文件已备份」。
- **文本级差异（Work）**：差异项按类型分组（公式、公式结果、表格单元格、插入表格）；每项展示位置（如 `预算总表!B8`）、修改前（红删除线）、修改后（绿底）、说明；底部备份说明、「恢复上次写入」、「查看文档」。

## 6. 浮层

| 浮层 | 规格 |
| --- | --- |
| 命令面板 | 宽 640px；搜索 + 模式标签；分组列出命令、会话、文件；↑↓ 选择、回车执行、Esc 关闭 |
| 设置中心 | 920×660；左侧七组导航（通用、模式、模型与提供商、工具与权限、MCP 服务器、外观、高级）；顶部可搜索；底部版本与路径。模型分组空态提供「从模型目录添加」与「手动添加」；目录浏览器左选提供商、右筛选勾选模型 |
| 审计 / 用量 / 备份 | 860×620 三标签；审计按风险与决定过滤；用量四张指标卡、按模型条形图、最近 7 天柱状图；备份恢复有确认 |
| 下拉菜单 | 圆角 10px；用于工作区、模型、审批档位、会话更多、文件右键 |
| 确认对话框 | 440px；危险操作红色确认按钮 |
| 输入对话框 | 重命名会话、添加命令前缀；回车确认 |
| 通知 | 右下角堆叠，4–8 秒自动消失；四种级别；审批、完成、失败通知可点击回到会话 |

浮层层级：面板浮层 32 → 面板全屏 34 → 下拉 200 → 命令面板/设置/数据 300 → 确认/输入对话框 360 → 通知 400。

## 7. 状态与反馈

| 会话状态 | 表现 |
| --- | --- |
| 空闲 | 输入框与发送可用；列表显示「已完成」 |
| 运行中 | 头部「运行中」徽章；列表脉冲点；输入区显示停止 |
| 等待审批 | 头部「等待审批」；列表黄点；审批卡片置顶；输入区显示「取消本次 run」 |
| 错误 | 头部「出错」；列表红点；错误卡片提供重试、切换模型、复制 |
| 已被替代 | 助手消息降透明度，顶部「该回复已被替代」 |

反馈组件：Toast（操作结果，不遮挡主操作区）、提示条（外部修改、扫描件不可读、草稿不发送、备份可恢复）、内联状态（加载态、进度条）、空态（无会话 / 无结果 / 无差异 / 未选文档，均给下一步说明）。工具卡片运行中旋转图标与耗时，完成后自动展开输出；流式末尾闪烁光标，停止即移除；长任务以 toast 或状态文案提示，不阻塞聊天。

## 8. 视觉规范

### 8.1 色彩 token

**深色主题**

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0b0d11` | 页面背景 |
| `--bg-panel` | `#101318` | 侧栏、面板 |

### 8.4 图标与品牌

- 全部功能图标来自 `lucide-react`，经统一 `<Icon name size strokeWidth>` 组件使用，不手写 SVG path；画布 24×24、默认描边 1.75；工具栏 14–16px、空态 20–24px、品牌 22px；颜色跟随 `currentColor`。
- 图标名与 lucide 组件的映射集中在 `frontend/src/components/Icon.tsx`；新增图标只在该表登记。
- 品牌标识使用 `frontend/public/logo.png`（1024×1024 源图，界面用 256px 版本）；应用图标由同一张图生成 `.icns` 与 `.ico`。不使用装饰性插画，空态只用单色图标 + 文案。

### 8.5 主题

- 跟随系统为默认，深色、浅色可选；三套选择同一 token 名称。
- 跟随系统时按 `prefers-color-scheme` 解析写入根元素并监听变化；固定主题后移除监听。
- 代码主题与界面主题分开设置；主题切换立即作用于所有区域。

## 9. 交互规范

- **模型与档位**：模型选择与审批档位都只影响下一次 run，放在输入框附近；风险等级提示（信息图标）逐行说明 R0–R4 判定与当前档位下的实际处置。切换到自由档位前必须弹出风险确认弹层（`FreeLevelDialog`）：展示将放行的能力清单（文件和文件夹、终端命令、网络和应用）与风险提示，必须勾选「我已了解风险，并对自己的数据安全负责」后才能确认；取消或关闭弹层保持原档位。
- **审批**：卡片在消息流内展示不遮挡内容；决定后立即刷新并写审计；审批不自动超时，关闭会话或取消 run 视为拒绝。
- **文件与链接**：`path:line` 点击在右侧文件页签打开（面板关闭或停留在其他页签时自动切过去）；Markdown 外链只允许 HTTP / HTTPS，点击先确认域名再走系统浏览器；拖放文件添加附件，拖放目录提示添加工作区。
- **面板**：宽窗口拖左边缘 320–760px；窄窗口浮层；全屏覆盖中间区域保留侧栏；编辑器搜索等局部操作尽量保持滚动位置，切换标签或文件回到顶部。

## 10. 可访问性与国际化

- 焦点：可交互元素用原生按钮或带 `role` 元素，焦点环 2px 强调色描边。
- 键盘：命令面板、设置、对话框均可键盘完成；审批卡片 Tab 顺序「拒绝」在最前。
- 对比度：正文与背景满足可读性；风险与状态不只依赖颜色，同时有文字与图标。
- 动效 150–200ms，无自动播放或强闪烁。
- 屏幕阅读器 v1 支持有限，在设置页与发布说明中说明。
- 文案走消息编号，支持简体中文与英文；日期数字按区域格式化。
- 界面字号、代码字号、终端字号可调，立即生效并重启保留。
