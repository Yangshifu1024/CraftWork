## 1. 设计目标与原则

### 1.1 设计目标

1. **让 Agent 的工作过程可见**：读文件、调工具、等待审批、写入差异、运行测试，每一步都在界面中有明确位置与状态。
2. **把风险放在用户眼前**：写文件、执行命令、修改文档必须先经过审批；审批内容展示原始路径、命令、风险等级与影响范围。
3. **两种模式、一套骨架**：Code 与 Work 共享三栏结构与工作区，只改变可用工具、右侧面板内容与会话列表。
4. **专业工具的密度感**：13px 基准字号、紧凑的 28–32px 控件、清晰的分隔线，避免大圆角与过度留白。
5. **键盘优先**：常用操作两次按键内可达，焦点始终可见，状态不只依赖颜色。

### 1.2 设计原则

| 原则 | 落地方式 |
| --- | --- |
| 本地优先 | 所有状态与数据在本地；界面不出现云端同步、账号登录等入口 |
| 审批不诱导 | 审批卡片默认拒绝，主要视觉权重不在“允许”；R3 / R4 不提供永久允许 |
| 信息分层 | 主操作（发送、允许一次）与次要操作（更多、复制）通过位置与字重区分 |
| 渐进披露 | 工具输出、推理内容、文件树、差异详情默认折叠，按需展开 |
| 一致性 | 同一语义使用同一组件与颜色：风险等级、状态点、徽章、卡片结构 |
| 可撤销感 | 写入前备份、软删除 7 天、差异逐块应用，界面持续提示可恢复 |

## 2. 整体框架

### 2.1 页面结构

页面没有独立顶栏。左侧栏标题行、聊天头部、右侧面板标签栏共用页面顶部 48px 的一行，三栏内容从同一水平线开始。

```text
【顶部 48px，一行】
  左侧：CraftWork 标题
  中间：会话标题 · 模式徽章 · 状态徽章 · 会话操作（面板 / 重命名 / 复制 / 归档 / 更多）
  右侧：面板标签（文件 / 差异 / 终端）· 全屏 · 刷新

【主体三栏】
  左侧 268px：模式切换 → 工作区卡片 → 会话列表
  中间：消息流（用户、助手、工具、审批、待办、草稿）→ 输入区
  右侧：文件树 / 编辑器 / 差异 / 终端；Work 模式为文档预览 / 文本级差异 / 文件
```

### 2.2 栅格与尺寸

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| 顶部行 | 48px | 左侧标题行、聊天头部、面板标签栏统一高度 |
| 左侧栏 | 268px 固定 | 不提供拖拽与折叠 |
| 聊天区 | 自适应 | 最大内容宽度 880px，居中显示消息流与输入框 |
| 右侧面板 | 默认 320px（最小宽度），可拖拽至 760px | 窄窗口自动折叠 |
| 最小窗口 | 960 × 640 | 低于 1180px 宽时右栏折叠 |

### 2.3 窗口行为

| 场景 | 行为 |
| --- | --- |
| 左侧栏 | 固定 268px，不可拖动、不可折叠 |
| 右侧栏（宽窗口） | 三栏并排；拖拽面板左边缘调整宽度，宽度写入本地偏好 |
| 右侧栏（窗口 < 1180px） | 自动折叠，聊天区占满剩余宽度 |
| 窄窗口展开面板 | 点击聊天头部的面板按钮，右栏以浮层覆盖聊天区右侧，不挤压聊天内容 |
| 面板全屏 | 点击面板标签栏的「全屏」按钮，右栏从左侧栏右边缘覆盖到窗口右侧；再次点击或按 `Esc` 恢复 |
| 跨阈值缩放 | 缩窄时自动折叠并退出全屏；放大时恢复三栏分栏 |
| 窗口状态 | 主题、模式、面板宽度本地持久化；窗口尺寸由系统恢复 |
| 折叠动画 | 收起 / 展开右栏时宽度与透明度做约 260ms 缓动过渡（滑出 / 滑入）；拖拽调整宽度期间禁用过渡保证跟手；浮层与全屏态不参与裁切以保留外投影 |

## 3. 左侧栏

### 3.1 结构

```text
268px 左侧栏（自上而下）
├─ 48px 标题行：CraftWork（居中）
├─ 模式切换：Code | Work（占满宽度）
├─ 工作区卡片：名称 / 路径 / 信任 / 分支 / 切换箭头
├─ 会话区标题：CODE 会话 + 数量 + 搜索 + 新建
├─ 会话列表（可滚动）
└─ 底部两行：用量 / 审计；命令面板 / 设置
```

### 3.2 标题行

- 高度 48px，与聊天头部、面板标签栏底线对齐。
- 内容为品牌标识（立方体描边图标）与「CraftWork」文字，整体在侧栏宽度内水平居中。
- 底部 1px 分隔线，颜色为 `--border`。

### 3.3 模式切换

- 位于标题行下方，占满侧栏宽度（左右各 10px 边距），整体高 40px、圆角 10px、深底描边轨道。
- 两个等宽按钮：`Code` 与 `Work`，带图标与文字，高 32px；**选中项为模式强调色实底滑块**——Code 蓝底白字、Work 琥珀底白字（深色主题 Work 为琥珀底深字，由 `--on-mode-accent` 决定），选中文字 600 字重；滑块携带模式色软投影（`0 2px 10px --mode-accent-soft`）使用 160ms 缓动平移。
- 未选中项为灰色图标文字，hover 提亮。
- 模式强调色：Code 使用蓝色 `#5b9dff`（浅色 `#2563eb`），Work 使用琥珀色 `#f0b354`（浅色 `#b06f0c`）。
- 切换模式后：会话列表、右侧面板内容、输入框占位文案立即变化；工作区不变。

### 3.4 工作区卡片

| 元素 | 说明 |
| --- | --- |
| 工作区图标 | Code 模式为打开文件夹，Work 模式为公文包 |
| 名称 | 例如 `craftwork`，右侧带当前模式徽章 |
| 路径 | 等宽字体，10.5px，超长省略 |
| 信任徽章 | 绿色「信任」/ 黄色「受限模式」/ 灰色「未选择」；点击展开信任设置 |
| 分支 / 文档数 | Code 显示 `main ↑2`，Work 显示文档数量 |
| 切换箭头 | 卡片右下角，点击展开最近工作区与「添加工作区」 |

### 3.5 会话列表

- 分组标题：`CODE 会话` / `WORK 会话`，带数量徽章、搜索按钮、新建按钮。
- 列表项两行信息：
  1. 会话标题（超长省略，独占一行）；
  2. 元信息行左右分布：时间在左，状态在右——运行中（脉冲点）、等待审批（黄色）、错误（红色）、已完成（灰色）；搜索内容命中时在时间与状态之间显示橙色「内容命中」标记。
- 当前会话：背景 `--bg-active`、左侧 2px 模式强调色竖条。
- 右键菜单：右键会话标题弹出应用内菜单（阻止系统默认菜单），包含三项：
  1. **复制会话 Id**：把后端唯一标识写入剪贴板并提示，用于日志排查与问题反馈；
  2. **重命名**：弹出输入框，新标题立即保存，与顶部工具栏的重命名共用同一流程与文案；
  3. **删除**：危险样式，确认框通过后连同消息、事件与审批记录一起删除，与顶部「更多操作」的删除共用同一流程。
- 自动命名：新建会话首轮消息后，如果标题仍是「新对话」，首条消息不超过 20 个字符时直接使用原文，否则调用当前模型生成短标题；模型失败时回退到首条消息提取；用户手动改名后不再覆盖。
- 搜索：按标题与消息内容过滤，标题命中高亮，内容命中显示「内容命中」；搜索只在当前模式的会话内进行。

### 3.6 底部两行

| 行 | 内容 | 行为 |
| --- | --- | --- |
| 第一行 | 用量、审计 | 打开用量统计 / 审计记录浮层 |
| 第二行 | 命令面板 `⌘K`、设置 `⌘,` | 打开命令面板 / 设置中心 |

底部区域通过 `margin-top: auto` 贴底，不随会话列表高度“浮到中间”。

## 4. 聊天区

### 4.1 会话头部

```text
会话标题   [Code]   [等待审批]                    [面板] [重命名] [复制] [归档] [更多]
```

- 高度 48px，与左侧标题行同高。
- 标题最多一行，超长省略。
- 模式徽章使用对应模式色；状态徽章按运行中 / 等待审批 / 出错显示。
- 右侧按钮：面板开关（配合窄窗口折叠）、重命名、复制会话、归档、更多（含软删除）。
- 背景为 `--bg` 与 `--bg-panel` 的混合色，带轻微模糊，滚动时内容不干扰标题。

### 4.2 消息布局

聊天软件式布局：不使用头像与作者名，内容占满消息流宽度。

| 角色 | 布局 |
| --- | --- |
| 用户 | 靠右侧气泡：底色 `--mode-accent-soft`、1px `--mode-accent-line` 边框、圆角 12px（右下 4px），最大宽度 78%；时间小字贴在气泡下方右侧 |
| 助手 | 全宽无边框内容区；时间小字在消息末尾 |
| 系统提示 | 居中细条，灰色或琥珀色，用于「上下文已压缩」「已停止生成」等 |

消息末尾的元信息行包含时间与 `已被替代` / `生成中` 标签（常显）；复制、重新生成等操作按钮悬停消息时浮现：

- 用户消息：复制；
- 助手消息：复制、重新生成。

### 4.3 内容块

| 内容块 | 视觉与交互 |
| --- | --- |
| Markdown 文本 | 13px / 1.68 行高；标题 15–17px；列表、引用、分隔线、表格、任务列表齐全 |
| 行内代码 | 等宽字体、`--bg-active` 底色、4px 圆角 |
| 文件引用 `path:line` | 蓝色描边 chip，裸文本与反引号行内代码形式都生效；点击在右侧文件面板打开文件，目标行垂直居中 |
| 代码块 | 语言标签、行号开关、自动换行、复制、超长折叠；复制内容不含行号 |
| 推理内容 | 虚线边框折叠条，显示耗时；默认折叠，展开后为 11.5px 次要文本 |
| 工具卡片 | 左侧状态色竖条（运行中蓝 / 完成绿 / 失败红 / 等待黄）；工具名、风险徽章、参数摘要、耗时；展开显示参数与输出，可复制输出 |
| 待办卡片 | 任务清单 + 进度条 + `2 / 4` 计数；完成项勾选并删除线，进行中项高亮 |
| 审批卡片 | 见 4.4 |
| 错误卡片 | 红色边框；错误分类（如 `context_overflow`）、原因、按错误码给出的处理建议、重试 / 切换模型 / 复制错误 |
| 邮件草稿卡 | 收件人、主题、正文、生成时间；「仅应用内显示」徽章与复制按钮 |
| 提示条 | 信息 / 警告 / 成功 / 强调四种；用于边界说明、备份提示、扫描件不可读等 |

### 4.4 审批卡片

```text
┌── 2px 风险色条 ───────────────────────────────────────
   需要你的批准    R1    fs_edit                  等待决定
   摘要：把 Exchange 网络调用移出写锁，回写前做二次检查
   路径：internal/auth/session.go
   事实：修改 2 个文件 · 写入前备份 · R1 写工作区
   差异预览（可展开）                          查看完整差异
     -  s.mu.Lock()
     +  sess, ok := s.sessions[sid]
   操作：拒绝 | 允许一次 | 本会话允许 | 本工作区始终允许
   提示：默认选中“拒绝”；Esc 拒绝；R3 / R4 不提供永久允许
```

规则：

- 风险等级徽章使用 R0–R4 专用颜色，只出现在风险语境，不做装饰。
- 展示工具名、原始路径或命令、影响范围；文档写入额外展示段落 / 单元格级差异。
- 默认焦点在「拒绝」，不允许默认选中「允许」。
- 允许范围：拒绝、允许一次、本会话允许、本工作区始终允许；R3 / R4 仅前两项；严格与只读档位下也仅前两项。
- 决定后卡片变为绿色（已允许）或灰色（已拒绝），显示时间、范围与「已写入审计」。
- 多个审批排队时逐个处理。

### 4.5 输入区

```text
┌── 输入框 ─────────────────────────────────────────────
   描述你要修复的问题、要实现的需求，或粘贴一段报错…

   📎  🖼  │  🛡 分级 ▾        ≈ 20.4k / 200k   ● Claude Sonnet 4.5 ▾   ⬆
⌘↵ 发送   Esc 停止生成
```

| 位置 | 元素 | 说明 |
| --- | --- | --- |
| 左侧 | 附件、图片 | 打开示例附件选择；支持拖放与粘贴图片；当前模型不支持图片输入时禁用图片按钮 |
| 左侧 | 审批档位 | 盾牌图标 + 分级 / 严格 / 只读 / 自由；点击切换，与设置双向同步 |
| 右侧 | 上下文占用 | 圆环 + 输出速度 + 占用百分比：`◯ 42 tok/s · 10%`；圆环按占用比例描边（<50% 灰、50%–80% 黄、≥80% 红）；悬停显示「上下文占用 N%」；点击展开详情面板（当前上下文数值与百分比、本会话累计、最近一轮缓存命中与速度） |
| 右侧 | 模型选择 | 绿色状态点 + 模型名 + 箭头；点击展开模型列表；与上下文间隔 12px |
| 右侧 | 发送 / 停止 | 发送为模式强调色方块按钮；运行中或等待审批时显示停止按钮 |

- 输入框随内容自动增高（最大 220px）。
- 空输入且无附件时发送按钮禁用。
- 运行中禁止发送；等待审批时提示先处理审批，或点击停止取消整个 run。
- 附件以 chip 展示，可移除；单条最多 20 个，单文件上限 50MB（提示值）。
- 下方提示条固定显示快捷键；不承载工具范围信息。

### 4.6 滚动与空状态

- 默认跟随底部；用户上滚超过 80px 后停止跟随，并在输入区上方显示居中的「回到底部」按钮。
- 新消息到达时若正在跟随则自动滚动；否则保持阅读位置。
- 空会话显示模式图标、标题、一句说明与三条建议快捷输入。

## 5. 右侧面板

### 5.1 标签与工具条

| 模式 | 标签 |
| --- | --- |
| Code | 文件、差异、终端 |
| Work | 文档、差异、文件 |

- 标签栏高 48px，与左侧标题行、聊天头部对齐。
- 差异标签带未应用文件数徽章；终端标签带标签数量徽章。
- 右侧固定两个图标按钮：**全屏**（放大 / 还原图标切换）与**刷新**。
- 面板左边缘 6px 拖拽热区，宽窗口下可调整宽度；浮层与全屏时隐藏。

### 5.2 文件树（Code）

- 工具条：过滤输入框、全部折叠按钮。
- 元信息行：仓库名、文件数量、变更数量、Git 状态说明。
- 树行：缩进 13px/层，目录使用文件夹图标，文件按扩展名着色（Go 蓝、Markdown 灰、Word 蓝、Excel 绿、PDF 红）。
- Git 状态字母 `M / A / D / U` 显示在最右侧；Work 模式不显示 Git 状态。
- 点击文件在编辑器打开；右键菜单提供打开、复制相对路径、在文件管理器中显示、移到废纸篓。

### 5.3 代码编辑器

- 顶部面包屑（`internal / auth / session.go`）与语言徽章、只读 / 编辑中徽章。
- 工具条：返回文件树、搜索、编辑或保存、复制。
- 行号列固定，当前行左侧 2px 强调色；语法高亮使用关键字紫、字符串绿、数字橙、注释灰。
- 底部状态：行数、编码、换行符、只读说明。
- 编辑态使用 CodeMirror 6，保存前弹出确认并提示自动备份；外部修改会阻止覆盖。

### 5.4 代码差异

- 摘要：文件数、`+42 −7` 统计、统一 / 并排切换。
- 文件列表：路径、增删统计、待应用 / 已应用徽章。
- 统一视图：旧行号、新行号、符号、代码四列；新增绿底、删除红底。
- 并排视图：左右两列配对显示，空行使用斜纹占位。
- 每个差异块头部提供「应用此块」「跳过」或「已应用 / 已跳过」；底部提供「应用当前文件全部块」。
- 应用后对应块降透明度并标记已应用；底部提示备份状态。

### 5.5 终端（Code）

- 多标签：`zsh`、`dev` 等，可新建与关闭；关闭时提示进程组清理。
- 头部：当前目录、Shell 类型、「用户终端不经过 Agent 审批」。
- 输出区由 xterm.js 渲染，连接 Go 侧真实 PTY；支持 16 色 / 256 色 / 真彩色、中文宽字符与滚动缓冲。
- 输入直接由终端接收，支持 shell 自身的历史与 `Ctrl+L` 清屏。

### 5.6 文档预览（Work）

| 类型 | 展示 |
| --- | --- |
| Word | 纸张页面、标题 / 副标题 / 段落 / 表格 / 落款；段落悬停显示段落号；变更段落黄色高亮，新增内容绿色高亮 |
| Excel | 公式栏（单元格引用 + 公式）、行列网格、工作表标签；标题行合并；变更单元格黄底描边 |
| PDF | 只读页面、页码；扫描页提示「不支持 OCR」；工具栏不提供备份 |

- 文档工具栏：文件名、格式与大小、缩放（70%–150%）、备份、只读 / 已写入徽章。
- 外部修改提示条：检测到文档被外部修改时提供「重新加载 / 保留当前」。

- 当前版本（M0）只展示文件信息与纯文本预览；Word / Excel / PDF 的结构化解析在 M3 接入，界面标注「预览模型」。

### 5.7 文本级差异（Work）

- 摘要：文件名与待审批 / 已应用状态。
- 差异项按类型分组：公式、公式结果、表格单元格、插入表格。
- 每项展示位置（如 `预算总表!B8`）、修改前（红色删除线）、修改后（绿色底）、说明。
- 底部：备份说明、「恢复上次写入」、「查看文档」。

## 7. 状态与反馈

### 7.1 会话状态

| 状态 | 表现 |
| --- | --- |
| 空闲 | 输入框与发送可用；会话列表显示「已完成」 |

## 9. 交互规范

### 9.1 模式与工作区

- 模式切换位于左侧栏顶部，切换后会话列表与面板内容立即变化，工作区保持不变。
- 工作区切换入口为工作区卡片右下角箭头，展开最近工作区与「添加工作区」。
- 信任状态可随时撤销；受限模式下写入与执行都必须审批。

### 9.2 模型与审批档位

| 控件 | 位置 | 行为 |
| --- | --- | --- |
| 模型选择 | 输入框右下角、上下文右侧 | 点击展开模型列表，支持按模型 / 提供商搜索；显示提供商、能力与上下文窗口；列表为空时显示“未配置模型”，发送按钮禁用；切换只影响后续 run |
| 审批档位 | 输入框左下角、附件之后 | 分级 / 严格 / 只读 / 自由；严格与只读隐藏永久允许；与设置 · 工具与权限同步 |
| 风险等级提示 | 档位选择器后方 | 信息图标：hover 显示一句概要；点击展开浮层，逐行说明 R0–R4 的判定与默认处置，并注明实际处置随当前档位变化 |

档位行为：

| 档位 | 审批卡片选项 | 说明 |
| --- | --- | --- |
| 分级（默认） | 拒绝、允许一次、本会话允许、本工作区始终允许（R1/R2）；R3/R4 仅前两项 | 与需求文档 R0–R4 默认策略一致 |
| 严格 | 拒绝、允许一次 | 所有写入与执行逐次询问，不提供永久允许 |
| 只读 | 拒绝、允许一次 | 界面标注「只读档位」，真实产品会阻止写入与执行 |
| 自由 | 不再出现审批卡片 | 放行所有操作（含 R4）；切换前弹出风险确认框，逐条列出后果，确认后才切换，取消保持原档位 |

受限工作区下，审批卡片不显示「本会话允许 / 本工作区始终允许」，网络命令直接拒绝；信任工作区按上表执行。自由档位例外：受限工作区的断网保护也被关闭，这是用户确认后的显式选择。

自由档位的视觉与交互约束：

- 输入框左下角的档位按钮在自由档位下整体转为危险色（`--danger`），让高危状态在发送消息前一眼可见。
- 设置 · 工具与权限中的档位单选卡与浮层选项同步增加「自由」项，共用同一确认守卫；两处入口行为一致。
- 审批卡片的档位标签显示「自由」。

### 9.3 审批

- 审批卡片在消息流内展示，不遮挡聊天内容；多个审批按顺序出现。
- 决定后立即刷新卡片状态，并写入审计记录。
- `Esc` 在无浮层、无全屏面板时，若当前会话等待审批则拒绝最近一条审批。
- 审批不自动超时；关闭会话或取消 run 视为拒绝。

### 9.4 文件与链接

- `path:line` 引用点击后在右侧面板的文件页签打开该文件（面板关闭或停留在其他页签时自动切过去），并把目标行垂直居中显示；文件不存在时提示。引用既识别裸文本，也识别被反引号包成行内代码的形态（整体恰好是一个引用才转换）；代码块（围栏）内的内容保持原文，不做转换。
- Markdown 中的外部链接只允许 HTTP / HTTPS；点击先弹确认框显示域名，再用系统浏览器打开。应用内不加载外部网页。
- 拖放文件到聊天区添加附件；拖放目录提示可作为工作区添加。

### 9.5 面板

- 宽窗口：拖拽面板左边缘调整宽度，范围 320–760px。
- 窄窗口：面板自动折叠；聊天头部按钮以浮层打开。
- 全屏：面板覆盖中间区域，保留左侧栏；`Esc` 或再次点击还原。
- 编辑器搜索、文档缩放等局部操作会尽量保持当前滚动位置；切换标签或文件时回到顶部。

## 11. 可访问性与国际化

- **焦点**：所有可交互元素使用原生按钮或带 `role` 的元素，焦点环为 2px 强调色描边。
- **键盘**：命令面板、设置、对话框均可用键盘完成；审批卡片按钮按 Tab 顺序排列，「拒绝」在最前。
- **对比度**：正文与背景对比度满足可读性要求；风险与状态不只依赖颜色，同时有文字与图标。
- **动效**：动画时长 150–200ms；不提供自动播放或强闪烁动效。
- **屏幕阅读器**：v1 支持有限，设置页与发布说明中明确说明。
- **国际化**：文案走消息编号，支持简体中文与英文；当前原型只实现中文，英文切换为占位。
- **字号**：界面字号、代码字号、终端字号可调，修改立即生效并在重启后保留。

## 12. 与需求文档的差异说明

需求文档 4.2 / 4.3 的示意包含独立顶部栏（Code / Work 切换、工作区、模型、运行状态、设置）。经过评审，原型调整为以下结构，**以实现为准**：

| 项目 | 需求文档示意 | 当前方案 | 原因 |
| --- | --- | --- | --- |
| 顶部栏 | 独立 48px 顶栏 | 无独立顶栏；左栏标题行、聊天头部、面板标签栏共用 48px 一行 | 减少一条水平分割，中间内容获得更多垂直空间；标题与三栏自然对齐 |
| 模式切换 | 顶部栏 | 左侧栏标题行下方 | 与会话列表、工作区同属导航区，切换成本更低 |
| 工作区切换 | 顶部栏 | 工作区卡片右下角箭头 | 位置贴近工作区信息，减少顶栏控件数量 |
| 模型切换 | 顶部栏 | 输入框右下角、上下文右侧 | 与本次 run 的输入上下文放在一起，切换只影响后续 run |
| 运行状态 | 顶部栏 | 聊天头部徽章、会话列表状态点 | 状态与会话绑定，避免顶栏常驻信息噪音 |
| 命令面板 / 设置 | 顶部栏图标 | 左侧栏底部第二行 | 顶栏取消后统一收纳到导航区；快捷键不变 |
| 工具范围 | 输入框底部 | 不单独展示；工具风险在审批卡片逐次呈现 | 输入区聚焦任务输入；审批档位入口在输入框左下角 |
| 右侧面板 | 固定分栏 | 宽窗口分栏；窄窗口自动折叠；可全屏覆盖 | 保证窄窗口下聊天区可读；全屏用于阅读长文档与差异 |

原型对需求文档其他交互的覆盖情况与已知限制，见 `docs/prototype/README.md` 第五节与第七节。

## 13. 设计决策记录

| 编号 | 决策 | 结论与理由 |
| --- | --- | --- |
| D-UI-01 | 取消独立顶栏 | 三栏顶部共用一行，减少纵向分割；模式、模型、工作区各自贴近使用场景 |
| D-UI-02 | 模式切换下沉到左栏 | 模式改变的是会话与工具集合，与导航同区更符合心智 |
| D-UI-03 | 模型与审批档位放在输入框 | 两者都只影响下一次 run，放在提交动作附近，降低误切换成本 |
| D-UI-04 | 审批档位四档 | 分级对应需求默认策略；严格与只读用于更保守场景；自由档位放行一切但切换前强制风险确认，兼顾高级用户效率与风险感知 |
| D-UI-05 | 左栏固定、右栏自适应 | 左栏是导航与会话入口，需要稳定宽度；右栏是工作产物，可折叠与全屏 |
| D-UI-06 | 全屏面板覆盖而非挤压 | 窄窗口下挤压会让聊天区不可读；覆盖保留上下文，`Esc` 可快速还原 |
| D-UI-07 | 风险色仅用于风险 | 避免红色/橙色被当作普通强调色，保证审批与错误信息始终醒目 |
| D-UI-08 | 深浅主题同 token | 便于前端通过 CSS 变量切换主题；代码主题独立配置 |
| D-UI-09 | 不内置任何提供商，也不做推荐排序 | 产品只提供 models.dev 目录作为可选数据源，提供商与模型全部由用户添加；设置页只保留“可用 / 未配置”这类功能性状态，不展示内置、自定义、已覆盖等来源徽标 |

## 14. 已知限制与后续建议

### 14.1 原型限制

- 原型为 HTML 实现，正式产品为 Wails3 + React + TypeScript；原型的 CSS 与 DOM 结构直接作为前端基线，交互与视觉以本方案为准，技术实现以《技术设计方案》为准。
- 国际化仅提供中文文案，英文为占位选项。
- 代码编辑器只读预览，编辑态不写盘；终端为命令模拟；Office / PDF 为 HTML 模拟渲染，不解析真实文件。
- 审批、审计、用量、备份均为前端模拟数据，不落库。
- 屏幕阅读器支持有限。

### 14.2 后续建议

1. **窄窗口细化**：在 960–1180px 区间进一步压缩聊天消息的内边距与卡片按钮布局，避免审批按钮换行拥挤。
2. **组件化落地**：将消息块、审批卡片、差异块、文档预览抽象为可复用组件，统一状态与间距 token。
3. **主题扩展**：在深色 / 浅色之外评估高对比度主题，满足低视力用户。
4. **国际化补全**：为全部文案建立消息编号表，补齐英文与日期 / 数字格式。
5. **视觉回归**：在 Wails3 前端实现后，以原型为基线对三栏布局、审批卡片、差异视图做截图对比；M0 手动对照，M1 接入 Playwright。
