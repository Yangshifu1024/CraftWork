# ADR-0011：邮件与日历经 MCP 只读，草稿仅应用内

- 状态：Accepted
- 日期：2026-10

## 背景

办公场景的高频需求是「总结邮件、准备回复、安排日程」。让 Agent 直接操作邮箱与日历意味着自动发信与自动建会的风险：误发、骚扰、不可撤销的外发动作。

## 决策

- 邮件与日历**通过 MCP 接入**，应用内置推荐服务器模板（只含地址、命令、权限说明与授权方式，不预置账号与密钥）。
- **只读**：读取邮件列表、正文、附件元数据与日历事件；读取操作记录审计；首次连接必须信任。
- Agent 生成**应用内草稿**（邮件回复草稿、日程安排草稿），用户复制到邮件客户端或日历应用后自行发送与创建。
- **不提供**：发邮件、创建或修改日程、服务端草稿、网页内容读取（v1）；浏览器自动化（后续版本）；浏览器仅用系统浏览器打开链接。
- OAuth 令牌与刷新令牌存 keys.json 的 `mcp` 节；邮件与日历内容视为不可信数据，只发送给用户选择的模型。

## 后果

- 不存在「Agent 替用户发信」的事故面；外发动作永远在用户自己的邮件客户端完成。
- MCP 信任与授权模型复用 ADR-0003 的审批体系。
- 体验上的代价：发送多一步复制粘贴；换来的是外发零风险。
