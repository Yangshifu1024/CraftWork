# ADR-0012：取消独立顶栏，三栏共用 48px 一行；左栏固定、右栏自适应

- 状态：Accepted
- 日期：2026-10

## 背景

需求早期的界面示意包含独立顶栏（模式切换、工作区、模型、运行状态、设置都放顶栏）。原型评审发现顶栏常驻信息噪音大，且多一条水平分割压缩了内容垂直空间。

## 决策

- **无独立顶栏**：左侧栏标题行、聊天头部、右侧面板标签栏共用顶部 48px 一行，三栏内容从同一水平线开始。
- 各控件就近放置：模式切换在左侧栏顶部（与会话列表、工作区同属导航区）；工作区切换在卡片右下角；模型选择与审批档位在输入框（都只影响下一次 run，放在提交动作附近）；运行状态用聊天头部徽章与会话列表状态点；命令面板与设置入口在左侧栏底部。
- **左侧栏 268px 固定**（导航与会话入口需要稳定宽度）；**右侧面板自适应**（默认 320px，可拖至 760px，窄窗口 < 1180px 自动折叠，可浮层覆盖或全屏，`Esc` 逐级还原）。
- 面板全屏用覆盖而非挤压——窄窗口下挤压会让聊天区不可读。
- 窗口最小 960×640；聊天内容最大宽 880px。

## 后果

- 中间内容区获得更多垂直空间；三栏顶部天然对齐。
- 13px 基准字号、28–32px 控件的专业工具密度感。
- 界面规格（尺寸、token、交互细节）以 `docs/specs/interface.md` 为准。
