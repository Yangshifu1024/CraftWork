# ADR-0002：Code / Work 双模式，工作区独立于模式

- 状态：Accepted
- 日期：2026-10

## 背景

产品同时服务开发者（读码、改码、跑命令）与日常办公（文档、邮件、日历）。两个用户群需要的能力与风险面完全不同：办公场景不应看到 Shell、Git 与终端，开发者场景不应被文档面板挤占。另一个选择是把所有能力塞进一个工作台按需显隐。

## 决策

- 显式的**双模式**：顶部侧栏 Code / Work 切换；模式是工作台级切换，只改变界面、可用工具与会话列表。
- **会话按模式分开**：Code 会话与 Work 会话互不混用（`threads.mode`）。
- **工作区独立于模式**：同一个文件夹可以在两种模式下打开，无需重复添加。
- Work 模式**隐藏** Git、差异面板、终端与 Shell 工具；保留文件树、文件预览、文档预览与文本级差异。
- 明确不做：同一会话内切换模式。

## 后果

- 办公用户的可见能力集与风险面显著缩小（无 Shell 即无命令注入面）。
- 界面骨架（三栏）两种模式共享，切换成本低；右侧面板标签与会话列表随模式变化。
- 工具注册需要按模式过滤可见性；MCP 服务器可配置可见模式（Code、Work 或两者）。
