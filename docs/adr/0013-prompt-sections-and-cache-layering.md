# ADR-0013：系统提示词分节组装 + 三层缓存

- 状态：Accepted
- 日期：2026-11

## 背景

系统提示词包含恒定内容（产品身份、行为契约）与每次运行才确定的内容（模式、工作区、日期、Git 状态、指令文件）。整段拼接会让任何一点变化击穿全部提示缓存；把易变事实混进稳定段则让缓存永远无法命中。

## 决策

- 提示词由 `internal/agent/prompt` **分节组装**，变化频率越低越靠前：

| 顺序 | 节 | 缓存层 | 内容 |
| --- | --- | --- | --- |
| 1 | prefix | 单独成块，无标记 | 产品身份一句 |
| 2 | identity | stable | 授权安全边界 + 行为契约 |
| 3 | mode_rules | dynamic | 模式声明、工作区、受限条款 |
| 4 | env | dynamic | 日期、平台、Shell |
| 5 | git_context | dynamic | Git 快照 |
| 6 | instructions | dynamic | 全局与项目 AGENTS.md |

- `Build` 输出最多三个 `model.SystemBlock`：前缀块（无缓存标记）、稳定块（stable 节合并，带标记）、动态块（dynamic 节合并，带标记）。
- **稳定块与运行时事实严格隔离**：模式、路径、受限状态、日期、Git、指令文件一律不进稳定块（契约测试强制）。
- Anthropic 在历史尾部追加第三个缓存断点；OpenAI 兼容以固定拼接规则保证请求前缀字节稳定，利用自动前缀缓存。节内文案与分隔符不得随手改动——字节变化即缓存失效。
- 纯组装不做 IO：环境事实由 `envcontext` 收集快照后传入；读取失败降级省略，不阻断对话。
- 只写行为哲学，不镜像工具清单（工具能力由请求的 `tools` 字段承载）。

## 后果

- 跨会话、跨模式的稳定块长期命中缓存；动态块变化只击穿自身。
- 提示词文案、结构与契约测试三处一致（`docs/specs/prompt-contract.md` 为契约基准）；变更需同步测试与该 spec。
